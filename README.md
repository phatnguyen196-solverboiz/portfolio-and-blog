# Nguyen Trong Phat — Portfolio & Blog

A responsive personal portfolio with four sections: About / CV, Projects, Technical Blog / Notes, and Contact. English is the default language, with a Vietnamese switch in the header.

## Run locally

The website uses plain HTML, CSS, and JavaScript. Open it with a local static server, for example `npx serve .`, then visit the printed URL. No build step is needed.

## Files

- `index.html` — page structure and contact links
- `styles.css` — responsive visual design
- `app.js` — bilingual content, projects, and notes
- `favicon.svg` — site icon

Project descriptions are based on the linked GitHub repositories. The technical notes were written for this portfolio from the implementation themes in those projects.
